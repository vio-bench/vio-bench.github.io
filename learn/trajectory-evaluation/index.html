Before you begin: Read coordinate frames without guessing

Establish corresponding poses first

Before computing an error, put estimated and reference poses in the same physical sensor frame and use consistent units. Associate timestamps under a stated tolerance or interpolation policy. Record the interval that has valid reference data. Matching the wrong timestamps or comparing camera poses with IMU poses can create errors unrelated to the estimator's motion accuracy.

Absolute error depends on alignment

Absolute trajectory error compares corresponding poses after a specified alignment. For position RMSE, p̂_i is the aligned estimated position, p_i the reference position, and N the number of evaluated correspondences. Positions are in meters, so this RMSE is also in meters.

SE(3) alignment estimates rotation and translation; Sim(3) also adjusts scale. For gravity-aligned VIO, yaw-plus-translation alignment preserves gravity alignment while removing the usual unobservable global freedoms. Full SE(3) additionally fits roll and pitch, and Sim(3) removes a scale discrepancy. State which transform is allowed and which poses fit it: these choices change what the score measures.

position RMSE = sqrt((1/N) ∑_i ‖p̂_i − p_i‖²)

Relative error compares motion segments

Relative pose error (RPE) compares estimated and reference motion between pose pairs. Specify whether pairs are separated by time, distance, or frame count, the segment length, and the pair-selection rule. Report translation and rotation units explicitly. Segment error in meters is different from distance-normalized drift in percent; angular error in degrees differs from degrees per meter. State any normalization.

evo provides absolute and relative pose error tools with selectable pose relations and alignment options. Save the evaluation command and settings with the result so another reader can reconstruct what the number measures.

Missing output is not zero error

A low error over a short surviving interval does not establish good performance over a whole recording. For a transparent report, record initialization time, output gaps, final output time, reference availability, and the number of attempted runs. Label incomplete runs and evaluation failures explicitly.

Choose the denominator before computing coverage. For example, matched reference samples divided by eligible reference samples measures sample coverage under a particular association policy. It is different from time coverage or completed-run rate. This is a reporting choice for the exercise, not an adopted VIOBench protocol. Publish the definition alongside the value.

SVO Pro

Combines a semi-direct visual frontend with a sliding-window visual-inertial backend derived from OKVIS. Optional global mapping and loop closure extend the odometry pipeline.

Public source codeRead the documentation

What to learn from this system

Connect image alignment, landmark tracking, and window optimization.

Documented inputs

  • Stereo + IMU
  • Mono / stereo visual odometry
Configuration matters

The upstream VIO guide documents separate mono and stereo EuRoC launch files. Global mapping and loop-closure modules are distinct options.

These are public upstream capabilities, not a statement that every mode has been run by VIOVERSE. Sources checked 2026-09-06.

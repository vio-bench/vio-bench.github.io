ROVIO

Fuses image-patch measurements and inertial readings in an extended Kalman filter. Its configuration exposes photometric or reprojection updates and online camera–IMU extrinsic estimation.

Public source codeDocumentation

Follow how an image residual updates a filter state.

Documented inputs

  • Mono + IMU
  • Multi-camera + IMU (build configuration)
Configuration scope

The default build enables one camera. Multiple cameras require ROVIO_NCAM and matching calibration; this is an upstream capability, not a verified VIOBench configuration.

These are public upstream capabilities, not a statement that every mode has been run by VIOVERSE. Sources checked 2026-09-06.

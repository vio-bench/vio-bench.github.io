ROVIO

Fuses image-patch measurements and inertial readings in an extended Kalman filter. Its configuration exposes photometric or reprojection updates and online camera–IMU extrinsic estimation.

Mono + IMU · Multi-camera + IMU (build configuration)

Implementation details
Optimization

SVO Pro

Combines a semi-direct visual frontend with a sliding-window visual-inertial backend derived from OKVIS. Optional global mapping and loop closure extend the odometry pipeline.

Mono + IMU · Stereo + IMU · Mono / stereo visual odometry

Implementation details
Optimization

VINS-Fusion

Estimates motion by optimizing visual and inertial constraints. The project also includes online camera–IMU calibration, visual loop closure, and an example GPS fusion pipeline.

Mono + IMU · Stereo + IMU · Stereo visual odometry

Implementation details
Optimization

BASALT

Provides visual-inertial odometry, mapping, and calibration tools. Its sliding-window estimator uses square-root optimization and marginalization, with separate visual-only examples.

Stereo + IMU (documented EuRoC / TUM VI examples) · Stereo visual odometry (KITTI example)

Implementation details
Filter

OpenVINS

Uses an error-state MSCKF with the current IMU state and correlated IMU pose clones. Sparse feature tracks constrain these states after feature elimination; optional SLAM landmarks and calibration states extend the filter.

Mono + IMU · Synchronized stereo + IMU · Synchronized binocular + IMU

Implementation details
Optimization

Kimera-VIO

Processes visual and inertial measurements for state estimation, with optional loop closure and mesh generation. Its EuRoC examples expose frontend and backend parameters separately.

Stereo + IMU · Mono + IMU

Implementation details
Optimization

ORB-SLAM3

Tracks visual features and optimizes camera or visual-inertial states, with place recognition and multiple-map management. Its examples allow the effect of IMU input to be examined on the same dataset.

Mono + IMU · Stereo + IMU · Mono / stereo / RGB-D visual SLAM

Implementation details
Optimization

DM-VIO

Extends direct sparse odometry with inertial estimation and delayed marginalization. Image timestamps, camera calibration, and synchronized IMU measurements are explicit parts of the dataset interface.

Mono + IMU · Mono visual odometry (useimu=0)

Implementation details
Learned frontend + optimization

AirSLAM

Uses a neural network to detect points and lines, then combines feature association with geometric optimization. A separate relocalization pipeline matches query images to a previously built map.

Stereo + IMU · Stereo visual SLAM · Mono relocalization into an existing map

Implementation details
Optimization

OKVIS2-X

Extends keyframe visual-inertial SLAM with a factor graph that can incorporate dense depth, LiDAR, and GNSS. Dense observations support volumetric submaps for mapping and navigation.

Multi-camera + IMU · Optional depth / LiDAR / GNSS

Implementation details
Filter

sqrtVINS

Uses a square-root covariance filter with an LLT-based measurement update and dynamic initialization. Its upper-triangular factor U satisfies P = UᵀU, where P is the state-error covariance.

Mono + IMU · Stereo + IMU

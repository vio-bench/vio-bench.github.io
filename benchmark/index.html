VIOverse benchmark

We compare 11 open-source VIO systems on 98 selected sequences from five public datasets. All reported results come from our own experiments and evaluations. Trajectory error is reported together with valid-path coverage, complemented by computational profiling on desktop and embedded platforms.

Evaluated systems

We select 11 open-source VIO systems spanning a decade of development, from 2015 to 2025. The suite combines direct, KLT-based, descriptor-based, and learned visual processing with filtering- and optimization-based state estimation. The table summarizes the design characteristics reported in the paper and the camera modes evaluated in this benchmark.

Monocular and stereo configurations are evaluated separately when available. Loop closure and global map optimization are disabled to focus on local visual–inertial estimation.

Reported measurements

Trajectory error
Position and orientation ATE, and translational and rotational RPE over specified segment lengths. Errors use SE(3) alignment without scale fitting and retained valid trajectory portions.
Valid-path coverage (SR)
The percentage of the complete reference path covered by valid estimates. SR is averaged over three expected runs per sequence. Only runs with SR ≥ 75% contribute to ATE and RPE.
Runtime and resources
Reported native processing time, CPU utilization, and process memory for each profiling input and platform. Native timings retain implementation-specific measurement boundaries.

Metric definitions and aggregation are provided alongside the results.
